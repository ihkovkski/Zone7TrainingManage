# ระบบบริการอบรมและวิทยากร สนง.คลังเขต 7

เว็บแอป 1 ไฟล์ (`index.html`) + Firebase Firestore — ฟรีทั้งหมด โฮสต์บน GitHub Pages
ล็อกอินด้วย **ชื่อผู้ใช้ + รหัสผ่าน** ที่ Admin สร้างเองในเว็บ (ไม่ต้องตั้งค่า Authentication ใน Firebase)

## ความสามารถ
- **ความเชี่ยวชาญ** — Admin เพิ่ม / แก้ไข / ลบ รายการวิชา ดูได้ว่าแต่ละวิชามีวิทยากรคนใดบ้าง
- **วิทยากร** — เพิ่ม / แก้ไข / ลบ / ค้นหา, เลือกความเชี่ยวชาญได้ไม่จำกัด, นับจำนวนครั้งที่บรรยาย
- **การอบรม** — หน่วยงานที่จัด, ชื่อโครงการ, สถานที่, วันที่เริ่ม–สิ้นสุด, หมายเหตุ
- **จับคู่วิทยากร** — เลือกวิทยากรได้หลายคนต่อ 1 การอบรม
- **รายงาน** — กรองช่วงวันที่ / หน่วยงาน / วิทยากร, 3 แบบ, ดาวน์โหลด CSV (เปิดใน Excel), พิมพ์/บันทึก PDF
- **จัดการผู้ใช้ (Admin)** — เพิ่มผู้ใช้, กำหนดสิทธิ์ Admin / ผู้ใช้ทั่วไป, เปลี่ยนรหัสผ่าน, ลบผู้ใช้

---

## ขั้นตอนติดตั้ง (ประมาณ 10 นาที)

### 1) สร้าง Firebase + Firestore
1. ไปที่ https://console.firebase.google.com → **Create project** → ตั้งชื่อ (ปิด Google Analytics ได้)
2. แถบซ้าย หมวด **Databases & Storage** → **Firestore Database** → **Create database**
   → location `asia-southeast1 (Singapore)` → เลือก **Production mode**
   (ถ้าหาเมนูไม่เจอ กด ☰ มุมซ้ายบน หรือ "All products" แล้วค้นคำว่า Firestore)
3. แท็บ **Rules** → ลบของเดิม วางเนื้อหาจากไฟล์ `firestore.rules` → **Publish**

### 2) เอาค่า config มาใส่ในเว็บ
1. หน้าแรกของโปรเจกต์ → กดไอคอน **`</>`** (Web) → ตั้งชื่อแอป → Register
2. คัดลอกค่า `firebaseConfig` ไปแทนที่ใน `index.html` ตรง `// ====== ใส่ค่า Firebase config ของคุณตรงนี้`

### 3) ขึ้น GitHub Pages
1. สร้าง repository ใหม่ (Public) เช่น `training-system` → อัปโหลด `index.html`
2. **Settings → Pages** → Branch `main` / `(root)` → Save
3. รอ 1–2 นาที จะได้ลิงก์ `https://ชื่อบัญชี.github.io/training-system/`

### 4) เข้าใช้งานครั้งแรก
- ล็อกอินด้วย **`admin` / `admin1234`** (ระบบสร้างให้อัตโนมัติตอนล็อกอินครั้งแรก)
- ไปที่แท็บ **จัดการผู้ใช้** → **เปลี่ยนรหัสผ่าน admin ทันที** แล้วเพิ่มผู้ใช้คนอื่น ๆ

## ข้อควรรู้ (ความปลอดภัยแบบง่าย)
- รหัสผ่านถูกเก็บแบบเข้ารหัส (hash) ไม่เก็บเป็นตัวอักษรตรง ๆ
- แต่ฐานข้อมูลเปิดให้อ่าน/เขียนได้ — คนที่ไม่มีบัญชีจะเข้าหน้าเว็บไม่ได้ แต่ผู้ที่มีความรู้ด้านเทคนิคและได้ค่า config ไป สามารถเข้าถึงข้อมูลโดยตรงได้
- จึง **ไม่ควรเก็บข้อมูลลับ** (เช่น เลขบัตรประชาชน) และควร **สำรองข้อมูล** เป็นระยะ: แท็บรายงาน → "รายการการอบรม" ทุกช่วงวันที่ → ดาวน์โหลด CSV
- ลืมรหัสผ่าน admin: เข้า Firestore → collection `users` → ลบเอกสาร `admin` (ถ้าไม่เหลือผู้ใช้เลย ระบบจะสร้าง `admin / admin1234` ใหม่ให้)

## โครงสร้างข้อมูล (Firestore)
| Collection | ฟิลด์ |
|---|---|
| `users/{username}` | username, name, role (`admin` / `user`), passHash |
| `expertise` | name |
| `speakers` | name, position, org, phone, email, expertiseIds[], expertise (รายละเอียดเพิ่มเติม) |
| `trainings` | project, agency, location, startDate, endDate (`YYYY-MM-DD`), speakerIds[], note |
